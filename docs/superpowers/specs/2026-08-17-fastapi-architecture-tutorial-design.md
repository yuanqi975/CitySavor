# FastAPI 架构入门教程设计

## 目标与受众

为零基础学习者制作一份可编辑的中文 Word 教程。读者完成教程后，能够理解 FastAPI Web API 的基本工作方式，并能读懂一个按职责分层的待办事项 API 项目。

## 教学示例

示例为 Todo API：用户可注册、登录，使用 JWT 访问受保护接口，并只能管理自己的待办事项。技术栈限定为 FastAPI、SQLAlchemy、SQLite、Pydantic、JWT 与 Docker。

## 教学方案

采用循序渐进方式：先实现一个可运行的单文件接口，再解释其维护困难，并逐步拆分至路由、服务、数据访问、模型、数据模式与核心设施层。每章遵循「代码图片—白话解释—请求流向」节奏。

## 架构

目录边界如下：

- `routers/`：HTTP 路由、入参和响应协议。
- `services/`：业务规则与跨层编排。
- `repositories/`：SQLAlchemy 数据读写。
- `models/`：数据库表定义。
- `schemas/`：Pydantic 请求与响应校验模型。
- `core/`：配置、数据库、安全、依赖与异常处理。
- `main.py`：应用入口与路由装配。

普通请求流为「客户端 → 路由 → 服务 → 数据访问层 → SQLite」。受保护请求先经由 JWT 认证依赖解析当前用户，再进入路由和服务层。

## 内容范围

1. FastAPI 与 HTTP API 基础。
2. 最小可运行接口。
3. 分层架构的原因与完整目录结构。
4. Todo CRUD 的各层实现。
5. SQLAlchemy 和 SQLite 持久化。
6. 注册、密码哈希、JWT 鉴权和所有权控制。
7. 配置、依赖注入、统一错误处理。
8. Docker 打包、运行与接口文档。
9. 自动化测试入门、常见错误与学习路线。

## Word 成品

文档包含封面、目录、架构流程图、核心代码的图片展示、逐段讲解、完整项目代码附录和复制即可用的运行命令。架构图和代码图片均须清晰、可打印，并配合中文说明。

## 验收标准

- 对没有 Python Web 开发经验的读者，术语首次出现均有简明解释。
- 所有主要分层均有独立代码示例和职责说明。
- 从注册到创建待办事项的端到端请求流程完整。
- Docker、测试和典型 HTTP 错误均有最小可操作示例。
- Word 文件可直接打开、编辑和阅读。
